## 4. 行为对照表

| 场景                 | 原版                    | 本仓库默认（所有开关关闭）                                                     | 越狱模式开启                 |
| -------------------- | ----------------------- | ------------------------------------------------------------------------------ | ---------------------------- |
| `system` 字段        | 官方身份说明            | 同原版                                                                         | Persona + 破限规则分块       |
| `safety_check`       | 固定 `high`             | `high`                                                                         | 不发送                       |
| 自定义系统提示词     | 无此设置                | 留空 = 自动组装；填写后原样下发                                                | 填写后仍原样下发，不再替换   |
| 拒绝后已输出内容     | 丢弃                    | 丢弃（防撤回开启则保留）                                                       | 同默认                       |
| 拒绝轮次进上下文     | 否                      | 否（防撤回保留正文则进入）                                                     | 同默认                       |
| 拒绝回复「继续生成」 | 禁止                    | 禁止（开关可放开）                                                             | 允许                         |
| 拒绝回复可编辑       | 原版无编辑功能          | 内容保留时可编辑                                                               | 同左                         |
| 采样参数             | 不传                    | 可调                                                                           | 可调                         |
| 导出拒绝回复         | `CONTENT_FILTER` + 模板 | 同原版（保留内容时按正常结束）                                                 | 同默认                       |
| 其他原版功能         | —                       | 搜索、附件、分支、导入导出、朗读、主题、双语等全部保留                         | 同默认                       |
| 联网搜索             | 服务端执行              | 默认保留；搜索投毒可接管或改写展示                                             | 同默认                       |
| 自定义思维链         | 无此设置                | 默认关；启用后注入 system，关闭深度思考时回复上方显示「已注入思维链」          | 同默认                       |
| 浏览器工具           | 无此能力                | 默认关；开启后把勾选的工具声明给模型，本地执行并回传结果                       | 同默认                       |
| 虚拟工作区           | 无此能力                | 默认关；开启后 Agent 可读写 localStorage 虚拟文件，需确认写入 / 删除           | 同默认                       |
| 聊天模式             | 无此设置                | 输入栏四档：仅聊天 / 网页 Agent / PTC / 创造，决定下发哪些客户端工具与往返上限 | 同默认（与越狱模式互不影响） |
| NanoVM Slim          | 无此能力                | 默认启用、模型调用默认关；终端、按需工具链、镜像导入导出与配额                 | 同默认                       |
| 上下文分类           | 无此统计                | 每个会话记录最近一轮的 8 类构成，仅展示不进入请求                              | 同默认                       |
| 提示词注入工具       | 无此能力                | 默认关；开启后可自定义工具名与参数，强制 `tool_choice` 把正文写成参数再还原     | 同默认                       |
| 记忆节点管理         | 无此能力                | 设置 → 记忆可按标题 / 正文 / 标签筛选，卡片可就地编辑标题、正文与标签           | 同默认                       |
| Unkernel 页面        | 无此能力                | 桌面 + 应用启动器（80+ 应用）、终端、Wayland 窗口、GL / Vulkan；默认 Alpine    | 同默认                       |
| 会话置顶             | 无此能力                | 「…」菜单逐个置顶 / 取消置顶，多选后一键置顶或批量删除；置顶只在会话列表生效 | 同默认                       |
| DeepSeek 账号        | 官方客户端里是账号登录  | 数据管理里用账号 API Key 登录（平台 OAuth 需要宿主回调），登录后可同步昵称到「我的资料」 | 同默认                       |
